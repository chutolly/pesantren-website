# Website Pesantren Darul Hikmah

Proyek website pesantren berbasis Next.js App Router, TypeScript, Tailwind CSS, dan Lucide Icons.

## Data website

Seluruh konten contoh tersimpan di [`data/pesantren-data.json`](./data/pesantren-data.json): profil pesantren, sambutan pengasuh, program, PSB, fasilitas, berita, alamat, dan kontak.

Pemula dapat mengubah teks, tautan, dan informasi dengan mengedit file JSON tersebut. Foto dapat diganti dengan memperbarui path gambar di file JSON dan menaruh file gambar terkait di folder `public/images/`.

Pastikan JSON tetap valid: gunakan tanda kutip ganda untuk nama properti dan teks, serta koma antar elemen.

## Menjalankan proyek

```bash
npm run dev
```

Buka http://localhost:3000.
